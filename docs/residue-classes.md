# Residue Classes

Residue classes describe the structural condition of residue before or during trace handling.

| Class | Name | Function |
| --- | --- | --- |
| `R_p` | Produced residue | Names residue generated by execution or downstream effects. |
| `R_a` | Accessible residue | Names produced residue available for review. |
| `R_s` | Assigned residue | Names residue assigned to a route, proxy, institution, procedure, or interpretation. |
| `R_u` | Unreachable residue | Names produced residue that persists but is not directly reachable. |
| `R_b` | Bridge residue | Names residue that may connect unreachable residue to accessible review. |

## Class Notes

Produced residue is not automatically accessible.

Accessible residue is not automatically meaningful.

Assigned residue is not automatically originated by the assignee.

Unreachable residue is not automatically absent.

Bridge residue is not automatically full recovery.
