# Indices

ArbiterSTG 2.0 uses index scores as structured descriptors. Scores support review; they do not produce final judgment.

## RLCI: Residue-Loss Criticality Index

`RLCI` estimates the severity of residue loss, trace degradation, or failure of trace recruitability.

Suggested scale:

| Score | Description |
| --- | --- |
| 0 | No material residue loss identified. |
| 1 | Minor degradation; review remains substantially intact. |
| 2 | Moderate degradation; limits should be recorded. |
| 3 | Significant degradation; Limited Admission or Shadow likely. |
| 4 | Severe loss; bridge dependence, transfer, or Null likely. |
| 5 | Critical loss; trace is unrecoverable or structurally collapsed. |

## RAI: Residue Accessibility Index

`RAI` estimates how accessible residue is for post-execution review.

Suggested scale:

| Score | Description |
| --- | --- |
| 0 | No accessibility established. |
| 1 | Unreachable except by assertion or indirect claim. |
| 2 | Minimal proxy or fragmentary access. |
| 3 | Partial access with material limitations. |
| 4 | Substantial access with minor limitations. |
| 5 | Direct and reviewable access. |

## Future Indices

`SPI` and `JTI` are reserved for possible future use:

- `SPI`: Shadow Persistence Index
- `JTI`: Jurisdictional Trace Index

They should not be treated as finalized unless explicitly adopted.
